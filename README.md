# Gloire à Dieu — Application Android

Recueil de 885 chants chrétiens. Application 100% hors-ligne.

## Comment obtenir l'APK

1. **Forkez ce dépôt** sur GitHub (bouton "Fork" en haut à droite)
2. Allez dans l'onglet **Actions** de votre fork
3. Cliquez sur le workflow **"Build APK"**
4. Cliquez **"Run workflow"** → **"Run workflow"**
5. Attendez ~3 minutes
6. Téléchargez l'APK dans la section **Artifacts**

## Installation sur Android

1. Transférez l'APK sur votre téléphone
2. Allez dans **Paramètres → Sécurité → Sources inconnues** (activer)
3. Ouvrez le fichier APK et installez
