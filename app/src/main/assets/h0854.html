AINSI, JE VOUS ENVOIE

CELD 343 / M.A. DE KEYSER
1.Je vous envoie peiner sans récompense,
Servir sans gain, inconnus, oubliés,
Souffrir aussi la dérision, l'offense;
Je vous envoie pour Moi seul travailler.
Comme le Père m'a envoyé, ainsi je vous
envoie.
2.Je vous envoie vers les brebis errantes,
Panser leurs plaies, peiner, veiller, gémir,
Porter le poids de ces âmes souffrantes.
Je vous envoie pour mon saint Nom
souffrir.
Comme le Père m'a envoyé, ainsi je vous
envoie.
RefrainSerrons les rangs sous la bannière
De notre Roi victorieux.
Que rien n'altère La foi si claire
Qui nous unit au Fils de Dieu.
Je vous envoie, renonçant à vousmêmes,
Le cœur serré, vous donnant sans retour,
Quittant amis, parents et foyers même ;
Je vous envoie démontrer mon amour.
Comme le Père m'a envoyé, ainsi je vous
envoie.
C-L DE BENOIT
Amis, venez! le Maître nous entraîne:
Ouvrons nos cœurs tout grands à son
Esprit;
Que, pleins de feu, s'élancent dans l'arène
Les plus fervents : les tièdes sont bannis !
Pour être forts, vivons dans la prière
:
Avec le Christ, on peut braver
l'enfer.
Il est l'Ami, pour nous plus près
qu'un frère,
Il fait fleurir les cœurs les plus
déserts.
