LE SEIGNEUR M'AIME

CELD 199 / G. GUILLOD
1.Le Seigneur m'aime, Bonheur suprême,
Le Seigneur m'aime, Il est amour!
Je redirai toujours: Le Seigneur m'aime,
Le Seigneur m'aime, Il est amour!
2.Portant ma peine, Ma lourde chaîne,
Portant ma peine, J'étais perdu.
Je redirai toujours: Le Seigneur m'aime,
Le Seigneur m'aime, Il est amour!
3.Dieu dans sa grâce Prit à ma place,
Dieu dans sa grâce Prit son cher Fils.
Je redirai toujours: Le Seigneur m'aime,
Le Seigneur m'aime, Il est amour!
4.Le poids immense de mon offense,
Le poids immense tomba sur lui.
Je redirai toujours : Le Seigneur m’aime,
Le Seigneur m’aime, Il est amour !
5.Il purifie toute ma vie, il purifie avec son
sang.
Je redirai toujours : le Seigneur m’aime,
Le Seigneur m’aime, Il est amour !
